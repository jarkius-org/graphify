# Glossary

- **Curated project wiki:** Human-reviewed project knowledge under `docs/wiki`.
- **Generated graph wiki:** Rebuildable graph navigation under `graphify-out/wiki`.
- **Graph digest:** A dated markdown summary of `graphify-out/graph.json` and `GRAPH_REPORT.md` for durable memory.
- **Local index:** Rebuildable `.llmwiki/index.db` cache created by `core-llmwiki`.
- **Oracle Vault:** Durable cross-session memory under `~/.oracle-vault`.
- **Arra/Psi:** Optional retrieval or compatibility layer over promoted memory, not canonical storage.
